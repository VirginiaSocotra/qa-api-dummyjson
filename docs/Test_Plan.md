# Test Plan — DummyJSON API

## Objective

The objective of this project is to practice manual API testing using Postman and verify REST API behavior for users, authentication, validation and pagination.

## Test Scope

The project covers:

- GET requests
- POST requests
- PUT requests
- PATCH requests
- DELETE requests
- Authentication
- Bearer Token
- Positive and negative testing
- Validation testing
- Path Parameters
- Query Parameters
- Pagination
- HTTP status code verification
- Response body verification

## Test Environment

- API: DummyJSON
- Tool: Postman
- Test Type: Manual API Testing
- Protocol: HTTP/HTTPS
- Data Format: JSON

## Out of Scope

- Database testing
- Performance testing
- Security penetration testing
- Automated API testing

## Test Approach

Testing includes positive, negative and boundary scenarios. API responses are verified based on status codes, response bodies, returned data and expected API behavior.
